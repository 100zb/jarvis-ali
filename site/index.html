05 — Installerp. 05

Chez toi en quatre commandes.

Prérequis : Python 3.12+ · uv · une clé API Groq

Tu préfères une fenêtre ? L’app desktop Electron lance le même moteur : cd desktop && npm install && npm start. Un installeur Windows se génère avec npm run dist.
